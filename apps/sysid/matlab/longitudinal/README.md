# 종방향 플랜트 모델 (Simulink)

레퍼런스 트럭(Scania S 6x2 태그리프트, DC16 520, G33CM-R, [docs/29](../../../../docs/29_reference_truck_dynamics.md))의 종방향 동역학을 기본 Simulink 블록(룩업 테이블, 적분기, 게인, 스위치, 포화)만으로 만든 모델입니다. Simscape·Vehicle Dynamics Blockset·Stateflow 없이 돌아갑니다. 입력은 기록에 있는 적용 페달·기어비·클러치·리타더 단·엔진브레이크 플래그·브레이크 온도이고, 출력은 차속·엔진 토크·변속기 출력 토크입니다. 수치와 출처는 [docs/30](../../../../docs/30_can_like_signals.md)의 물리 검증·기어 고정 맵과 아래 맞춤 결과입니다.

## 실행

MATLAB에서 이 폴더로 이동한 뒤:

```matlab
fit_longitudinal_maps();        % 학습 실행에서 맵을 맞추고 longitudinal_fitted_tables.m을 다시 씀
build_longitudinal_model();     % longitudinal_plant.slx를 처음부터 다시 만듦
validate_longitudinal();        % 검증 실행 재생, results/에 json·mat·png (약 3분)
```

`load_recording("<run>")`은 `bridge/recordings/<run>/frames.jsonl`에서 `dt`(Tier 1 구동계 기록)가 있는 프레임을 읽어 `cache/<run>.mat`에 둡니다(git 제외). 모델 단독 실행은 `P = longitudinal_params("trailer")`(또는 `"truck"`)를 기본 작업공간에 두고 `u_ext = [t thr brk ratio clutch ret_level eb_flag brake_temp grade]`를 외부 입력으로 줍니다.

| 파일 | 내용 |
|---|---|
| `build_longitudinal_model.m` | 모델 생성 스크립트(.slx는 이것으로 재현) |
| `longitudinal_params.m` | 모든 파라미터와 출처. `"baseline"` 변형은 맞춤 전 문서 값 |
| `fit_longitudinal_maps.m` → `longitudinal_fitted_tables.m` | 데이터 맞춤과 그 결과(생성 파일) |
| `validate_longitudinal.m` | 구간·전체 재생, 파라미터 스윕, 결과 저장 |
| `load_recording.m`, `sg_derivative.m` | 기록 읽기, Savitzky-Golay 미분 |
| `results/` | `validation.json`, `fitted_maps.json`, 실행별 그림 |

## 구조

- Engine: 요구 토크 = 마찰 + f(스로틀, rpm)·(전부하 − 마찰). 엔진브레이크(B 플래그, 리타더 5단, 서비스 브레이크 0.5 이상일 때 자동)는 스로틀 0.05 이하에서 rpm별 표. 실제 토크는 요구 토크를 따르되 상승률을 (토크, rpm) 표로 제한(클러치가 붙어 있을 때, 터보 지연), 하강은 즉시.
- Gearbox_Clutch: 클러치 0.5 미만이면 엔진 회전 = 기어비 × 출력축 회전, 구동 토크 = 엔진 토크, 엔진 쪽 관성 J_locked가 차량 질량에 더해짐. 미끄러질 때 클러치 토크 = clamp(K·e·slip, ±C·e), e = (1−c)^1.5, 엔진은 J_free로 따로 돌고 발진 회전수(1,100 rpm)로 묶임. 보고용 출력 토크는 게임 채널 식 η·기어비·(1−c)·(Te − J_report·dω/dt).
- Retarder: 출력축 토크 = 기울기(단) × 출력축 회전, 1차 지연 0.05 s.
- Service_Brake: 트럭 바퀴 토크 합 = 입력 × 이득(브레이크 온도, 바퀴 회전), 트레일러 힘 표, 합계는 1.1·m·g로 제한. 압력 지연 파라미터(`P.brk.tau`, 기본 0).
- Vehicle: a = (구동 + 리타더 − 브레이크 − 3.0·v² − c·m·g − m·g·경사)/(m + 환산 관성), 차체 지연 0.2 s, 속도 ≥ 0.

## 맞춤에서 나온 것 (2026-10-20 실행)

- 마찰 −215.1 − 0.0512·rpm Nm(잔차 0.0 Nm, 게임 식 그대로). 부분 부하 비율 ≈ 1 − (1 − 스로틀)^1.33(잔차 0.007), rpm에 거의 무관.
- 토크 상승률은 상수(docs/30의 약 2,500 Nm/s)가 아닙니다. 800 rpm에서 1,400–1,900 Nm/s, 1,250 rpm 이상에서는 낮은 토크 3,400–3,900 Nm/s, 2,000 Nm 넘으면 1,800–2,500 Nm/s. 클러치가 열려 있으면 2–3프레임에 전부하.
- Tier 1 출력 토크는 η 0.972, J 16.0 kg·m²의 식을 정확히 따르지만(R² 0.9996), 차속으로 맞추면 엔진 쪽 관성은 4.6 kg·m²이고 질량은 19.9–20.6 t(docs/29와 같음)입니다. 출력 토크 채널로 질량을 맞추면 18.5–18.8 t로 작게 나오고 저단일수록 더 작아집니다(J를 과하게 빼는 채널). 모델은 둘을 나눠 씁니다.
- 리타더(관성 항 포함): 1–3단 −4.3 / −9.0 / −14.7 Nm/(rad/s). 4·5단은 이 기록에 없어 docs/30 값을 같은 기준으로 환산했습니다.
- 바퀴 브레이크 토크는 명령 다음 프레임에 도달하지만 차체 감속은 약 0.2 s 1차 지연으로 따라옵니다(클러치가 열려 구동이 끊길 때도 같음). 트럭 이득 = 119,080 − 274·온도 − 507·바퀴 rad/s Nm(상대 잔차 2.7 %). 트레일러 힘은 0.1 → 32, 0.3 → 50, 0.5 → 53 kN(힘 수지 잔차, 직접 측정 아님).
- 서비스 브레이크 0.5·1.0이면 엔진브레이크 플래그가 0인데도 엔진 토크가 −3,000 Nm가 됩니다(프로필 `g_motor_brake_auto 1`). 0.1–0.3에서는 없습니다.

## 남은 불일치

- 저단(6단, 기어비 5.87) 과도: 게임 출력 토크가 ±7–12 kNm로 출렁이고 엔진브레이크 직후 감속이 0.4 s 더 이어집니다. 강체 구동계로는 안 나옵니다(full:6 속도 0.5–0.6 m/s, 출력 토크 4.8–6.3 kNm RMS).
- 클러치 미끄럼: 게임의 미끄럼 중 출력 토크 채널은 구동력을 나타내지 않고(발진 중 300–400 Nm인데 3 m/s²로 가속), 모델의 클러치 토크는 스윕으로 맞춘 근사입니다. 발진 직후 accel:20(+1.1 m/s), 정지에서 14단부터 내려오는 스로틀 0.3 기어 내림(+1.3 m/s)이 빠릅니다.
- 엔진브레이크 8단: 같은 엔진 토크에서 게임 감속이 약 12 % 작습니다. 코스트 효율·관성을 스윕해도 전체로는 개선이 없어 그대로 두었습니다.
- 유턴(선회 저항 없음), 트레일러 브레이크 1.0(0.5 값 반복 + 마찰 한계), 리타더 4·5단(이 기록에 없음).
