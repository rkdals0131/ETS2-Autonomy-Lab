# 레거시 문서

2026-10-12에 목표를 "게임 안에서 자율주행이 되면 끝"으로 다시 정하고, 실행 환경을 WSL Ubuntu에서 Windows 네이티브로 옮기기로 결정하면서 아래 문서를 이 폴더로 옮겼습니다. 현재 결정은 [요구사항과 결정](../01_requirements_and_decisions.md), 구조는 [시스템 구조](../03_system_design.md), 작업 순서는 [Windows 네이티브 포팅 계획](../20_windows_native_port_plan.md)을 따릅니다.

이 폴더의 문서는 상대 링크 경로만 한 단계 깊어진 위치에 맞게 고쳤고 내용은 수정하지 않습니다. 코드와 설명이 다르면 코드가 맞습니다. 2026-10-12 P1로 WSL 경로 코드는 삭제됐습니다. 현재 운용 절차는 [브리지 사용법](../../bridge/README.md)이 설명합니다.
