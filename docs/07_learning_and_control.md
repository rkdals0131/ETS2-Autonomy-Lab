# Phase 1 인지와 제어

목표는 고속도로 ACC·차로 유지·사각지대 감시와 운전자 지시 차로 변경입니다. 현재 센서 전달은 구현됐고 입력·인지·제어는 다음 단계입니다.

## GT 폐루프부터 연결

1. **M8 입력:** 조향·가속·제동의 실제 적용 값과 해제를 연결합니다. 하나의 소유자, 0.2초 명령 만료, 수동 개입·F11 종료를 적용합니다.
2. **M9 ACC:** 차량 GT의 상대 거리·속도로 목표 속도와 간격을 제어합니다.
3. **M9 LCC:** 주행할 차로 중심·곡률·연결 경로의 GT를 확보해 추종합니다. 현재 차량 박스 GT에 차로 경로 입력을 추가해야 합니다.
4. **M10 인지:** 뷰별 차량·차선 인식과 추적을 넣고 같은 경로에서 GT 기준 대비 저하량을 비교합니다.

GNSS·IMU·휠 융합은 위치 추정 입력입니다. GT ego pose는 오차 평가에 사용합니다. RGB·라이다·레이더의 관측과 내부 GT는 토픽·모델 입력에서 구분합니다.

## 인지 구성

뷰별 경량 모델 → 객체·차선 추적 → 차량 좌표 융합 → ACC/LCC 순서입니다. 인지용 축소 영상에서 시작하고 장거리 검출에 필요한 뷰의 해상도를 올립니다. 게임과 추론은 같은 GPU를 쓰므로 end-to-end 지연과 프레임 시간을 함께 측정합니다.

기록은 run·경로·조건 단위로 학습·검증을 나눕니다. 사용자의 입력과 게임에 실제 적용된 조향·가감속을 함께 저장합니다. 주야간·날씨·트레일러는 필요한 장면부터 추가합니다.

## 지표

목표 속도·차간거리·차로 중심 추종 오차, 충돌·차선 이탈·사용자 개입, 센서 관측부터 명령 적용까지의 지연, 게임 프레임 p95/p99를 비교합니다. 같은 주행 구간에서 GT 입력과 센서 입력을 교체해 원인을 분리합니다.

시내·교차로·주차와 다중 카메라 BEV/E2E는 Phase 1 운용 후 확장합니다. 모델·체크포인트는 아직 선정하지 않았습니다.
