# 진행 상태와 개발 순서

2026-10-10 기준: FH5의 독립 센서 생성·ROS 전달·짧은 MCAP 재생을 확보했습니다. 입력 장치를 설치하고 disarmed Xbox 대조·ROS arm/disarm을 확인했습니다. GT 속도·조향 위치 목표로 FH4 실제 가속·조향·제동을 확인했습니다. 실제 지도 차로 기반 약453m 주행을 확인했습니다. 근접 앞차·경로 선택과 추종 개선이 다음 단계입니다.

| 단계 | 현재 상태 | 남은 완료 조건 |
| --- | --- | --- |
| M0 실행 기반 | SDK·메타로더·패닉·lease·재로딩·통합 런처 구현 | 30분 주행 안정성, 실제 F11 키 확인 |
| M1 렌더 경로 | pass 명령 구간으로 미러 식별·복사 | 완료 |
| M2 픽셀 확보 | 같은 렌더 프레임의 RGB·깊이 수집 | 완료 |
| M3 정합 | CPU/GPU 투영 대조, 이동 AI 박스·DSV 정합 | 트레일러·주행 장면 확대 |
| M4 자유 배치 | FH5 4뷰, 기본 미러 보존, 유휴 뒤 준비 렌더·요청 주기 수집 | 큰 캐빈 운동·고개 조작·트레일러 시야 |
| M5 가시성 | 자차 외판 복구, 정차 중 나무·가로등 깜빡임 수정 | 주행 재확인, 거리·뷰별 실제 누락률 |

| M8 입력 | 입력 SDK 등록, disarmed Xbox 대조, ROS arm/disarm, GT 속도·조향 위치 목표로 실제 가속·조향·제동 | 추종 오차 개선·armed 수동 해제/F11·만료 확인 |
| M9 GT 폐루프 | 실제 차로 생성·속도 PI·pure-pursuit·앞차 목표 제한, FH4 약453m 주행 | 근접 앞차 감속·속도 overshoot 개선·prefab/목적지 경로·차로 변경 |
| M10 인지 폐루프 | 미구현 | 같은 경로에서 GT 대비 성능 비교 |

## 다음 순서

1. 속도·조향 위치 추종 오차를 줄이고 armed 수동 해제·F11·만료 동작을 확인합니다. 첫 주행의 휠 오도메트리 회전 오차와 IMU 가속도·GNSS 정합도 보완합니다.
2. 바퀴별 실제 조향과 차량 반응을 식별하고 근접 앞차 감속을 확인합니다. 기존 GT 차로 추종을 prefab/목적지 경로로 확장합니다. [플랜트와 제어](07_learning_and_control.md).
3. 같은 주행에서 가시성·트레일러·센서 잡음을 확인하고 위치 추정·카메라·라이다 인지를 확장합니다.

성능 진단은 [A–G 비용 분해](18_performance.md)에 따릅니다. 센서의 세부 현실성 개선은 폐루프 개발과 함께 진행합니다.

## 구현 위치

- 게임: `ot/native`, 주소·필드: `ot/schema`
- Windows 릴레이: `bridge/windows`
- ROS 수신기·메시지: `bridge/ros2`
- 실행 관리: `bridge/launcher.py`, `bridge/wsl_session.py`
- 현재 리그: `ot/presets/phase1-highway-private.json`
- 라이다 패턴: `ot/presets/phase1-lidar-private.json`

현재 사용법은 [브리지](../bridge/README.md)와 [DLL](../ot/README.md), 중요한 실패와 해결은 [시행착오](history/lessons.md)에 있습니다.
