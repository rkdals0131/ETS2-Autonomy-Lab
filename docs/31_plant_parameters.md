# 31. 레퍼런스 트럭 플랜트 파라미터

레퍼런스 트럭에서 식별한 플랜트 파라미터를 한 곳에 모은 표입니다. Simulink 모델과 제어기 파라미터는 여기서 가져갑니다. 값은 출처 문서와 코드에서 그대로 옮겼고, 해석과 측정 과정은 각 출처에 있습니다.

## 개요

- 대상: Scania S 6x2 롱 태그리프트(`vehicle.scania.s_2016`), 엔진 DC16 520, 변속기 G33CM-R(리타더 5단). 트레일러 없음, 그리고 빈 개인 트레일러 `vehicle.scs.box`를 연결한 상태 두 가지입니다.
- 조건: 프로필 ETS_SysID, 사용자 평소 모드 구성(Realistic Truck Physics 9.2 포함), 게임 1.61.1.9, core 0.40.0, [시험장 패드](../bridge/testground_map/README.md)(평지). 프로필은 상대 조향(`c_relatsteer=1`), `g_motor_brake_auto 1`, `g_retarder_auto 1`입니다.
- 4x2(`이전 레퍼런스`) 값은 지금 트럭과 같다고 확인된 것(조향 계통)과 아직 6x2로 다시 재지 않은 것(브레이크 온도 페이드, 브레이크 지연)에만 씁니다. 표에 "4x2"로 표시합니다.
