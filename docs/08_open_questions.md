# 남은 작업

| 작업 | 현재 영향 | 다음 조치 |
| --- | --- | --- |
| 센서 수명주기 | 영상 중지에 IMU·GNSS가 함께 중단, 재연결 때 위치 기준 초기화 | 상태 읽기·측정 이력·영상 수집·통신 세션 분리 |
| 센서 구성 | 카메라·라이다 이름 고정, 상태 센서 단독 실행 불가 | 센서 목록에서 토픽·TF·주기·의존성 생성 |
| 차량 캘리브레이션 | truck ID만 검사, 같은 FH5의 부품 변경 미식별 | 실제 차량 기하·장착 부품에 맞는 프로필 선택 |
| 트레일러 외판·굴절 | 연결 후 측후방 가림과 제출 범위 미확인 | 실제 연결 주행에서 RGB·depth·점군 확인 |
| LOD·도로 visibility | 메인 시점의 선택이 센서 물체에 영향 | 센서 frustum actor와 pass 제출·영상 비교 |
| 긴 주행·주야간 | 짧은 정차 표본 중심 | 10분 기록과 30분 운용 |
| WSL 주소 변경 | 재조회 코드 구현, 실제 주소 변경 시험 남음 | 사용자 작업 종료 후 배포판 재시작·새 주소 연결 |
| 센서 충실도 | IMU·휠·가상 GNSS 정차 수신 완료 | 직진·선회·제동 정합, 공분산·잡음·RTK |
| 입력·플랜트 | 입력 API·제어용 응답 모델 미구현 | M8 소유권·해제·실제 적용값 → 응답 식별 → GT ACC/LCC |
| 원본 고해상도 비용 | 이전 10 Hz 전체 브리지 46.35 FPS | 30 Hz 원본 부하와 [A–G 측정](18_performance.md) |
